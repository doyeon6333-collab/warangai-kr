    원고를 붙여넣으면
    여기에 네이버 서식으로 보여요
    네이버에 붙여넣는 순서
    1. 네이버 블로그 → 글쓰기 → 에디터가 스마트에디터 ONE인지 확인
    2. 제목 칸에 제목을 따로 쓴 경우, 위 옵션에서 제목 줄 넣기를 해제
    3. 본문을 한 번 누른 뒤 Ctrl+V (휴대폰은 본문을 길게 눌러 붙여넣기)
    4. [사진n] 자리에 사진을 올리고, 사진 파일명은 3단계에서 미리 바꿔 두기
    5. 맨 아래 태그 칸에 해시태그 입력 → 발행

    서식이 일부 풀려 보이면 브라우저를 새로 고친 뒤 다시 복사해 보세요. 자동 발행 프로그램·매크로는 쓰지 마세요.

    모델 목록

    🔒 키는 이 브라우저(localStorage)에만 저장돼요. 서버로 보내지 않고, 원고를 만들 때 해당 AI 회사에만 직접 요청해요. 공용 컴퓨터에서는 쓰지 마시고, 다 쓰면 [키 삭제]를 눌러 주세요.

    커스텀 GPTs는 왜 API로 못 부르나요?

    ChatGPT의 커스텀 GPTs는 OpenAI가 외부 프로그램용 API로 열어 주지 않아요. 그래서 이 도구는 두 가지 길을 같이 제공해요.

    ① 0원 모드 — 1단계에서 만든 프롬프트를 ChatGPT(또는 쓰고 있는 블로그 글쓰기 GPT)에 직접 붙여넣고, 결과만 2단계에 붙이기(가장 정확하고 무료).
    ② AI 모드 — 같은 글쓰기 지침을 넣어 여기서 바로 생성(OpenAI 또는 Google Gemini 키 필요, GPTs와 문장이 조금 다를 수 있어요).

    AI에 심는 글쓰기 지침 보기 · 수정

    API 모드에서 쓰는 지침이에요. 내 글쓰기 방식에 맞게 고쳐도 돼요(이 브라우저에만 저장).

    이 도구에 대해

    와랑 AEO 블로그 스튜디오는 네이버 블로그 안전 작업 규칙(개인정보·실명 노출 금지, 얼굴·이름표 블러, 내부 자료 링크·프롬프트 노출 금지, 사진 파일명 블로그사진_…)에 맞춰 만들었어요.
    글·사진은 어디로도 전송되지 않고, 저장되는 건 입력한 내용과 설정뿐이에요.
